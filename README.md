# Polimorfismo Orientada a Objeto em Java

Este projeto foi desenvolvido com o objetivo de aprofundar meus conhecimentos em Programação Orientada a Objetos (POO), com foco no conceito de polimorfismo. Através de exemplos práticos implementados em Java, demonstro dois tipos principais de polimorfismo: o polimorfismo por sobrescrita (override) e o polimorfismo por sobrecarga (overload). A sobrescrita é aplicada quando uma subclasse redefine o comportamento de um método herdado da superclasse, enquanto a sobrecarga ocorre quando métodos com o mesmo nome são definidos com diferentes assinaturas dentro da mesma classe. O código foi estruturado de forma clara e didática, permitindo visualizar como esses mecanismos tornam o código mais flexível, reutilizável e aderente aos princípios da orientação a objetos. Este repositório faz parte do meu processo de aprendizagem contínua e pode servir como referência para estudantes ou desenvolvedores que desejam compreender melhor a aplicação prática do polimorfismo em Java.
